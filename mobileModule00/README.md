# Module 00 - Basic Flutter & Widgets

## Overview

Introduction to Flutter fundamentals through progressive exercises. Topics covered include widget basics, state management, layout design, and responsive design patterns.

## Exercises

### Exercise 00 - Basic Display

Create a basic Flutter application with UI components.

**Objectives:**
- Understand Flutter project structure
- Work with basic widgets (Text, Button)
- Implement state management in a simple widget
- Create responsive layouts

### Exercise 01 - Interactive Text

Implement text state changes based on user interaction.

**Objectives:**
- Manage widget state with setState()
- Handle button callbacks
- Update UI based on state changes

### Exercise 02 - Calculator UI

Build the user interface for a calculator application.

**Objectives:**
- Design complex layouts with Row and Column
- Implement AppBar and TextField widgets
- Create responsive button grids
- Practice widget composition

### Exercise 03 - Calculator Functionality

Implement full calculator logic with arithmetic operations.

**Objectives:**
- Parse and evaluate mathematical expressions
- Handle edge cases (division by zero, invalid input)
- Implement clear and delete operations
- Ensure application stability

## Getting Started

Each exercise is a standalone Flutter project:

```bash
cd exXX
flutter pub get
flutter run
```

## Key Concepts

- Stateless and Stateful widgets
- Widget composition and hierarchy
- State management with setState()
- Layout widgets (Row, Column, Stack)
- Responsive design principles
- Error handling

Focus on responsive design and error handling

Use appropriate libraries (math_expressions for calculator)

Evaluation Criteria
Functionality according to specifications

Code quality and organization

Responsive design implementation

Error handling and crash prevention

Proper use of Flutter concepts and widgets

Start with Exercise 00 and progress sequentially through each exercise, building upon your previous work to create a complete, functional calculator application.
