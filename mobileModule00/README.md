Piscine Mobile - Module 00: Introduction to Mobile Development
Overview
This module introduces mobile application development through a series of progressive exercises using Flutter. You'll build from basic UI components to a fully functional calculator application.

Exercise Structure
Exercise 00: A basic display
Objective: Create your first Flutter project with basic UI components

Requirements:

Single page with centered text widget and button

Display "Button pressed" in debug console when button is clicked

Application must be responsive

Key Concepts: Widget basics, state management, responsive design

Exercise 01: Say Hello to the World
Objective: Implement interactive text changes

Requirements:

Text toggles between initial text and "Hello World!" on button click

Reuse and modify Exercise 00 code

Key Concepts: State management, event handling

Exercise 02: More Buttons
Objective: Build calculator UI layout

Requirements:

AppBar with title "Calculator"

Two TextFields (expression and result display)

Complete calculator button layout (0-9, operators, AC, C, =, .)

Debug feature: print button text to console

Responsive design for all devices

Key Concepts: Layout design, widget composition, responsive UI

Exercise 03: It's Alive!
Objective: Implement calculator functionality

Requirements:

Perform basic arithmetic operations (+, -, *, /)

Handle multiple operations in single expression

Support negative numbers and decimals

Clear (AC) and delete (C) functionality

Error handling (division by zero, invalid expressions)

Application must never crash

Key Concepts: Math expressions, error handling, state management

Technical Requirements
Framework: Flutter
Google's UI framework for native iOS/Android development

Free and open source

Works with existing code
